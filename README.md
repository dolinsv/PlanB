# VK Mini App «Контент-план»

Личный планировщик постов с напоминаниями. Один общий JSON на сервере —
чтобы пользоваться вдвоём с разных устройств.

## Стек

- Frontend: React 18 + Vite + VKUI + VK Bridge
- Backend: Node.js (ESM) + Express + better-sqlite3 + node-cron
- БД: SQLite (`data.db`)

## Локальный запуск

```bash
cd vk-content-plan
npm install
cp .env.example .env
# впишите VK_GROUP_TOKEN (токен сообщества с правом messages)
```

Два терминала:

```bash
npm run dev:server   # API на :3000
npm run dev:client   # Vite на :5173, proxy /api → :3000
```

Откройте http://localhost:5173 — в браузере bridge-ошибки ожидаемы, UI и API работают.

Прод-сборка одной командой:

```bash
npm start
```

Сервер отдаёт `dist/` и API на `PORT` (по умолчанию 3000).

## Привязка к VK Mini App

1. Создайте мини-приложение в [VK для разработчиков](https://dev.vk.com/) / в управлении сообществом → Мини-приложения.
2. Укажите URL приложения (HTTPS): например `https://your-host/` после `npm start` / деплоя.
3. В настройках приложения включите уведомления; токен сообщества с правом `messages` положите в `.env` как `VK_GROUP_TOKEN`.
4. Откройте мини-приложение из VK: при первом заходе сработают `VKWebAppInit` → `GetUserInfo` → `/api/me` → запрос `AllowNotifications`.
5. Cron каждую минуту шлёт `secure.sendNotification` по постам с `publish_at <= now` и `reminded = 0`.

## Цвета в календаре

- Синий — пост
- Красный — клип
- Зелёный — сторис
- Зачёркнуто — уже разместили
- В ячейке (десктоп): до 2 слотов + «+N»; на мобиле — цветные точки
- Клик по дню открывает настройки дня

## Данные (общее для двоих)

Хранение — JSON-файл `data/store.json` на сервере (без SQLite).

Чтобы пользоваться **вдвоём с разных устройств**, нужен **один общий хост**
API (оба открывают один и тот же URL). Тогда посты, заготовки и история общие.

Локально: `data/store.json` создаётся при первом запуске; при наличии старого
`data.db` данные мигрируют автоматически.

## История

После срабатывания напоминания пост помечается как «разместили» и пишется
в историю (кнопка ⌛️ в шапке).

2. «Поделиться» → «На экран „Домой“».
3. Название: **PlanB**, иконка подтянется из `apple-touch-icon`.
